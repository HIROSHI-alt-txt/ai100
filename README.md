# AI重要人物100人 業界勢力図＆エグゼクティブ相関マップ

現代のAI革命を最前線で牽引する世界的なリーダー、研究者、起業家、投資家、政策担当者100名を網羅した、インタラクティブ業界勢力図ダッシュボードです。

---

## 🌟 主な機能

- **① 勢力図カオスマップ（Overview Matrix）**: 100名全員をメガアライアンス・陣営別に1画面俯瞰
- **② ホバーポップアップ解説**: チップにマウスを乗せると、経歴・功績・最新動向が即座に浮上
- **③ クリック詳細＆音声プレイヤー**: 各人物の詳細固定、および **ずんだもん（VOICEVOX）** による解説音声（約30秒）をワンクリック再生
- **④ 全編通しオーディオ（52分11秒）**: 100名＋イントロ・章案内をノンストップで聴き流し可能
- **⑤ サプライチェーン階層ビュー**: 半導体〜クラウド〜基盤モデル〜アプリ〜政策の垂直レイヤー構造で整理
- **⑥ 全100人テーブル**: スプレッドシートのように一望できる検索対応一覧表
